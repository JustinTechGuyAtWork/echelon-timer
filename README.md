# Echelon — Routine Builder & Timer

A web app for building, timing, and running Lagree/Pilates-style classes (routines → blocks → exercises with loads, sides, rest), with class plans, an exercise catalog, light/dark themes, and PDF/CSV/text export.

Open the live link on a phone, tablet, or computer. On a phone, use **Share → Add to Home Screen** to run it like an app.

Single-page app — `index.html` plus icon/manifest files. Data is stored per-device in the browser; use **Settings → Backup/Restore** to move routines between devices.
