Quick tips

  • Build a routine — add blocks (sections) and exercises with a time and optional rest. Each block has its own Class format (Lagree, Cycle, Treadmill, Strength) that sets its fields, e.g. Cadence & Resistance for cycle. Mix formats in one routine for crossover classes (e.g. a Cycle block then a Strength block).
  • Run it — tap a routine card (or ▶ Start). The timer auto-advances; use the on-screen buttons or Space / ← / → / Esc.
  • ◫ Plans — chain routines into one back-to-back class.
  • ☰ Moves — save go-to exercises per format; while building, start typing a name to auto-fill from a saved move.
  • Export — from a routine, get a PDF run sheet, spreadsheet, or text.
  • Your data stays on this device. Use Backup before switching phones/computers, then Restore on the new one.
  • Add to Home Screen (iPhone: Share → Add to Home Screen) to use it like an app.
